# Support

For help using Orbit:

- Read the [README](./README.md) for installation, usage, permissions, and
  troubleshooting information.
- Search the [existing issues](https://github.com/M003aad/Orbit/issues) for
  known problems. If your question or problem is not already covered, open an
  issue with the Orbit version, browser/version, and steps to reproduce.
- For feature proposals, use the issue tracker and describe the problem you
  want to solve.

Please do not post security vulnerabilities in public issues. Use the private
reporting channels described in [SECURITY.md](./SECURITY.md).
